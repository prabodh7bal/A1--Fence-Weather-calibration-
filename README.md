\## 📌 Problem



A-1 Fence's PIDS sensors are highly sensitive to weather conditions — heavy rain,

high wind, and storms frequently trigger false alarms. Operators currently adjust

sensitivity manually and reactively, which is slow and error-prone.



\## 💡 Solution



Vigil continuously pulls live weather data and feeds it into a trained \*\*Random

Forest classifier\*\* that recommends one of three sensitivity levels — \*\*High,

Medium, or Low\*\* — along with a genuine confidence score. Every recommendation is

logged for audit and historical analysis.

\## 🧠 Recommendation Engine



Since no real historical false-alarm dataset exists for A-1's deployment, we

generate a large synthetic dataset spanning realistic weather conditions, label

it using domain-expert thresholds (standard PIDS engineering guidance for

wind/rain/humidity/storm impact on sensors), and train a \*\*Random Forest

classifier\*\* on top of it. This lets the model learn feature \*interactions\*

(not just fixed thresholds) and produce real probability-based confidence

scores — see `train\_model.py` for the full methodology.



\*\*Feature importance\*\* (from the trained model):



| Feature      | Importance |

|--------------|-----------|

| Storm flag   | 39.6%     |

| Wind speed   | 25.6%     |

| Rainfall     | 23.9%     |

| Humidity     | 10.0%     |

| Temperature  | 0.9%      |

\## ▶️ Run Locally



```bash

\# 1. Install dependencies

pip install -r requirements.txt



\# 2. Train the model (creates model.joblib)

python train\_model.py



\# 3. Start the backend

uvicorn app:app --reload



\# 4. Open index.html in your browser

```



The backend runs at `http://127.0.0.1:8000`. Open `index.html` directly in a

browser — it will call the local backend by default.
